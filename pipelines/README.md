# 수집·정규화·적재 — 이찬용

관련 FR-007·008·012·020. 초기 적재는 첫 연결에 필요하고 자동 갱신은 별도 후속 작업입니다.
입력: 확인한 실제 데이터/API와 이용조건. 출력: backend/app/data가 조회하는 장소·출처·운영 구간.
원본 식별자·제공기관·URL·기준일·조회일·이용조건·좌표계를 기록합니다. 키와 원본 데이터는 저장소에 무조건 넣지 않고 데이터별 재배포 조건을 확인합니다.
운영시간 누락은 상시 영업, 가격 누락은 무료로 변환하지 않습니다.
먼저 한 권역 표본의 필드·누락률을 검토하고 원본 기준 PostgreSQL+PostGIS의 스키마·API 매핑을 김영무와 맞춥니다. SQLite 변경은 별도 제안입니다. 다른 팀원이 같은 절차로 적재할 수 있으면 완료입니다.
현재 실제 데이터와 수집 코드는 없습니다.
