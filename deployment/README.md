# 배포 구성 예정 영역
SDD 10장·배포 도식은 초안이다. 단일 VM의 Docker Compose에 nginx(React 정적 파일·HTTPS 프록시), API, 배치 실행을 둔다. DB는 별도 컨테이너 없이 SQLite 파일을 사용한다(DEC-005). 컨테이너 사이의 파일 공유 방식(공유 볼륨, 새 파일 교체)은 DECISIONS.md 미결 항목(이찬용·김영무, 11/24)에서 정한다.
김영무·이찬용이 기존 공동 배포 역할에 따라 검토하고 프론트 빌드는 배진호와 연결한다. 현재 Dockerfile/Compose/실제 배포는 없다.
SRS 2.3 운영 환경은 Linux/Docker·Python 3.12다(DEC-011). CI는 현재 3.11과 3.12를 함께 검사한다.
인메모리 세션은 단일 worker로 시작한다. 프록시 접근 로그의 세션 토큰·건강 원문 보호, 실제 TTL 폐기를 배포 전 검수한다.
