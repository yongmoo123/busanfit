# DB·PlaceRepository — 이찬용 · COMP-10
FR-007·008·012·020. 실제 DB 구현은 이찬용 담당이다. #23 연결을 위해 PR #15의 Repository Protocol·장소/출처 레코드·ID 규칙을 그대로 재사용했으며 SQLite 구현·공간 검색은 가져오거나 새로 구현하지 않았다.
입력: 정규화된 실제 장소/출처, 지원 검색 조건. 출력: 계약의 Place·Source 및 내부 운영시간 구간.
DB는 확정 결정 DEC-005의 SQLite를 따른다. 기존 PostgreSQL+PostGIS 안내는 결정 전 내용이다. 김영무와 Repository 입출력·복수 출처 매핑을 맞추며, 후보 판단은 retrieval/COMP-04에서 분리한다. 인터페이스를 가져온 것이 #15 승인·병합이나 실제 DB 연결을 의미하지 않는다.
좌표·원본 ID·중복·출처 연결·누락을 검증하고 UNKNOWN은 그대로 유지합니다.
외부 수집은 pipelines, 요청 시 검색은 이 영역입니다. 초기 적재 재현은 pipelines와 함께 검수합니다.
FR-017의 역·주차장·엘리베이터·보관함 조회도 담당합니다. FR-019 공유 저장은 Could 후속이며 세션/건강 원문 저장과 구분합니다.
