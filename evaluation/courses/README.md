# 코스 시나리오 평가셋 (초안)

담당: 김세민 · 관련: FR-008·009·012, AI-REQ-01·05, AC-004·010·011, NFR-001 · 이슈 #39·#28

실제 해운대 데이터로 만든 코스에 **없는 장소가 0건**인지(AI-REQ-01), **필수 조건 위반이 0건**인지(AI-REQ-05) 확인하는 시나리오 10개다. `cases.json`에 있다.

> **상태: 초안.** 실제 데이터 실행 결과는 없다. 스프린트 2 통합 점검(#28)에서 처음 실행한다.

## 구성
조건 추출 AI를 거치지 않고 **조건 프로필을 직접 넣는다**. 추출 오류와 코스 엔진 오류를 섞지 않기 위해서다.

| ID | 상황 | 확인하는 것 |
|---|---|---|
| CS-01 | 일반, 토 오후 4시간 | 기본 동작 |
| CS-02 | 일반, 저녁 3시간 | 마지막 주문 = 마감(DEC-023) |
| CS-03 | 휠체어 | 항목별 무장애 판정(DEC-015), 정보 없음 제외 |
| CS-04 | 영유아 가족 | 유모차 자동 적용(DEC-002·020) |
| CS-05 | 부상 | 구간당 도보 10분, 3 km/h(DEC-016) |
| CS-06 | 꼭 실내 | 실내 HARD (스프린트 2에 미지원이면 제외) |
| CS-07 | 카페·음식점 제외 | 제외 카테고리 |
| CS-08 | 1시간 30분 | 최소 2곳 경계 |

## 판정
- **공통 검사**(`commonChecks`): PR #50의 독립 검사기 `audit.py`와 같은 항목에 DEC-023 검사 2개(영업시간 정보 없는 장소, 사후면세점)를 더했다.
- `SUCCESS_OR_INSUFFICIENT`: 조건상 후보가 부족할 수 있는 시나리오다. 코스가 나오면 공통 검사를 모두 통과해야 하고, 부족하면 `INSUFFICIENT_PLACES`가 정답이다.
- `requiresSupport`의 항목이 꺼져 있으면 `EXCLUDED`로 기록한다.
