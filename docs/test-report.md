# 1. 테스트 개요

## 1.1 목적

부산핏 제출본(v1.0)이 SRS의 요구사항, 특히 하드 제약을 위반하지 않는 코스 생성(AI-REQ-05)과 DB에 있는 장소만 사용하는 근거 기반 응답(AI-REQ-01)을 충족하는지 확인하고, 남은 결함과 한계를 기록한다.

## 1.2 테스트 대상/제외 범위

- 대상: 제출본 구현 범위(DEC-028). 채팅 조건 입력·추출·강도 분류·되묻기, 기본값·조건 카드, 후보 검색·이동제약 판정, 도보 코스 생성·검증, 코스 시각화, 추천 이유·출처, 정보 없음 장소 포함 제안, 조정 제안 칩, 동행 가중치, 권역 확장(서면·광안리·남포), 대화형 수정
- 제외: 향후 과제로 넘긴 기능(대중교통·자차·편의시설, 예산 하드 제약, 배포·데이터 주기 갱신, 코스 공유), 외부 서비스(LLM·TourAPI·카카오맵) 자체의 내부 동작, 실제 보행 경로의 계단·경사(확인 불가로 `UNVERIFIED` 표시, DEC-016)
- 11/25 판단(DEC-036): 고정 일정(FR-010)은 제외(향후 과제). 날씨(FR-016)는 판정 모듈·실외 장소 목록(#87, A단계)만 단위 테스트 대상이고, 코스 반영(B·C단계)과 조정 칩 ③은 제외(향후 과제).
