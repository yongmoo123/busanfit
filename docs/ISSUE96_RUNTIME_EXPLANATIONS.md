## 변경

일반 app.main:app의 실제 DB 시작 연결 성공 뒤 ExplanationGenerator를 구성한다. 조건 추출·기본 수정 해석과 같은 AIService를 재사용하며 Repository는 실행 CourseService와 동일 객체다. 이미 열린 AIService 수명주기·연결 풀·스키마 캐시를 공유하고 다른 모델/키를 만들거나 .env를 읽지 않는다. 주입 앱은 기존 선택적 설명 연결을 유지하고 명시적 생성기 주입을 덮어쓰지 않는다. 종료/시작 실패 시 자동 생성기와 준비된 코스 연결을 해제한다.

기존 explain(course, mobility 범주, remaining_seconds)만 호출한다. 사용자 원문·세션·전체 프로필은 설명에 전달하지 않는다. 성공은 확인된 사실 키 선택을 시스템 문장으로 조립해 reasonMethod=LLM, 미설정·실패·예산 소진은 TEMPLATE와 AI_FALLBACK(placeIds)이다. API 형식·선택 장소·일정·하드 검증·기존 최대12초 설명 예산·시도당10초/1회 재시도는 변경하지 않았다.
