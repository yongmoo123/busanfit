# 원본 DOCX 대조와 구조 보완

검토일: 2026-10-27~28. 상태: 김영무의 원본 대조·구조 수정 요청을 반영한 작업안. 팀 전체 정책 변경 승인이 아니다.

## 결론과 확인 범위
계획서의 F1~F5, SRS의 FR-001~020, SDD의 COMP-01~12 및 팀 역할은 기존 Markdown과 전체 흐름이 일치한다. Markdown은 원본 부록 앞에 첫 주 축소 계획과 계약 보완안을 추가한 자료이며, 그 추가안을 원본 요구사항으로 취급하면 안 된다.
DOCX의 본문과 표를 직접 추출하고 SRS 이미지 2개·SDD 이미지 9개를 직접 열어 확인했다. 계획서는 내장 이미지가 없다. 학번과 서식을 제외한 텍스트 대조도 수행했다. 원본 DOCX는 변경하지 않았다.
10월 28일 재검사에서 비어 있지 않은 추출 문단(표 셀 문단 포함) 계획서 339개·SRS 797개·SDD 913개가 학번·공백·Markdown 기호 정규화 후 모두 해당 Markdown 내용에 포함됨을 확인했다. 이는 텍스트 포함 검사이며 레이아웃·문단 순서의 완전 동일성 검사는 아니다.
전체 페이지 렌더는 패키지 renderer가 LibreOffice 실행 파일을 찾지 못해 실패했다. 따라서 페이지 레이아웃·쪽수 검수 완료를 주장하지 않는다. 이 작업은 문서 생성이 아닌 구조·내용 대조다.

## 변경 범위
단일 FastAPI 앱과 기존 폴더는 유지하고 책임이 빠지거나 혼동된 위치를 보완했다. 새 폴더의 README는 개발 위치·역할 설명이며 기능 구현물이 아니다. 기존 계약의 경로·필드·상태·revision과 실행 코드는 변경하지 않았다.
구현자는 COMPONENT_MAP.md → REQUIREMENTS.md → 기존 계약 순서로 확인한다. 최종 요구사항·첫 주 축소 범위·현재 구현 상태는 별개다.
