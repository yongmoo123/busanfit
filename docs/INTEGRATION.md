# 통합 지점과 착수 순서

| 연결 | 담당 | 전달할 내용 | 검증 기준 |
|---|---|---|---|
| 화면 ↔ API | 배진호·김영무 | contracts의 5개 경로·상태·revision·오류 | 가상 화면과 실제 연결 시험을 구분, 실패 시 상태 복구 |
| 코스 ↔ Repository | 김영무·이찬용 | 지원 조건, Place·Source 및 운영 구간 | 실DB ID만 사용, 누락값 유지, 출처 연결 |
| 코스 ↔ 이동시간 | 김영무·이찬용 | 인접 장소·수단·정수 분·추정 방식 | 계산 불가를 0분으로 대체 금지, 시간창 검증 |
| 코스 ↔ 날씨 | 김영무·이찬용 | 날짜·지역·예보 기준시각·조회 실패 | 필수 판단에 필요한 실패를 숨기지 않음 |
| 구현 ↔ 평가 | 각 담당·김세민 | 요구사항 ID·기대 결과·실행 증거 | 미실행과 통과 구분 |

외부 API 형태는 기존 초안을 따릅니다. 내부 Repository/이동시간 함수 서명은 아직 확정하지 않았으며 양 담당자가 구현 전 정의합니다. 원본 DB 기준은 PostgreSQL+PostGIS입니다. 전체 책임 위치는 COMPONENT_MAP.md, 정책 충돌은 ORIGINAL_REVIEW.md에서 확인합니다.
