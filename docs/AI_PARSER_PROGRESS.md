# AIService·규칙 파서 골격 구현 기록

- 날짜: 2026-11-08
- 최근 보완: 2026-11-11 (검증 결과는 아래 후속 기록 참조)
- 상태: 이슈 #8 작업 E 중 추가 정책 합의 없이 가능한 범위의 구현·로컬 검증 완료. 2026-11-09 사용자 요청으로 develop 대상 PR 제출 단계, 팀원 검토·병합 전.
- 관련: FR-002 일부, FR-003, NFR-002·006, AI-REQ-02·03; DEC-001·006·007
- 작업 브랜치: feature/FR-002-ai-parser (확인한 origin/develop 기준)

## 구현

- AIService/Provider: 목적별 프롬프트·출력 스키마, JSON 검증, 시도당 10초 제한·최대 2회 호출, 안전한 내부 실패 코드, 외부 취소 전파.
- FakeProvider: 네트워크 없는 성공·지연·실패 재현. 받은 요청은 보관하지 않음.
- CourseContext: 사용자 원문은 추출·수정 해석 호출에만 허용하고, 설명에는 장소 ID·이동제약 범주만 전달하는 경계. 실제 설명용 장소 사실 모델은 후속 작업.
- 부분 추출 모델과 RuleBasedParser: 해운대·명시적 절대 날짜/시간·이동수단·이동제약·동행·영유아·단순 실내 선호. 미입력과 해석 불확실은 UNSET으로 유지하고 언급 후 미확인 필드를 별도 표시. 모호한 부정·시간을 추측하지 않음.
- DEC-001의 스프린트 2 이동수단 기본값 WALK만 적용. 다른 SOFT 기본값 전체를 정의한 것은 아님. 미지원 이동수단도 추출 힌트로만 반환하며 지원 여부를 결정하지 않음.
- 영역 README에 인터페이스·실행 명령·지원 문법·한계를 기록.

## 정책·통합 경계

PR #13의 세 정책은 2026-11-09 PM 결정 DEC-019~021로 확정됐다. 결정 기록 PR #18과 계약 PR #13의 병합 상태는 별개다. 2026-11-11 constraints/mobility.py에 DEC-020 정규화를 추가했다. USER의 []·기존 목록 우선, 해제 유지·null 초기화·영유아 취소와 경고를 구현했다. 파서는 부분 힌트만 추출하고, 정규화는 사용자 수정 이후 실행한다. HTTP·세션 연결과 503 판정은 기존 PR #13에서 구현한다.

AIService와 파서는 단독 모듈이며 서로의 대체 경로·세션·HTTP chat에 연결하지 않았다. 부분 추출 힌트를 기존 프로필에 바로 덮어쓰면 안 된다. 기존 HARD 보존·사용자 확인·API 프로필 변환은 후속 검토가 필요하다. 스키마 검증은 업무 의미 검증·공공데이터 사실 검증을 대신하지 않는다.

실제 LLM·모델·요금·이용조건 선택은 하지 않았다. 목적별 실제 업무 출력 스키마와 더 넓은 한국어 표현 처리는 미완료다. 파서 회귀 사례는 김세민 담당 AI 정확도 평가셋을 대체하지 않는다. 전체 FR-002나 작업 E의 리뷰·병합까지 완료한 상태가 아니다.

현재 develop 기준의 HTTP 계약은 5 operations다. 세션 종료 API는 별도 PR #12이므로 이 브랜치에 중복 구현하지 않았다. API 경로·필드·capabilities 변경은 없다.
